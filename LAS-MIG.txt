WEBBDESIGN – MARIAM KASAMBULA

Öppna projektet
1. Packa upp ZIP-filen.
2. Öppna mappen i Visual Studio Code.
3. Högerklicka på index.html och välj Open with Live Server.
   Tillägget Live Server måste vara installerat.

Filerna
index.html är startsidan.
om.html berättar om projektet och skaparen.
projekt.html innehåller en bildstudie.
kontakt.html innehåller e-post och länkar för vidare läsning.
css/style.css styr utseendet på alla fyra sidor.
js/script.js sköter knappen för större text.
images innehåller bilder och favicon.

Förstå koden inför redovisningen
HTML beskriver innehållet. CSS bestämmer utseendet. JavaScript reagerar på klick.
header är sidhuvudet, nav är menyn, main är huvudinnehållet och footer är sidfoten.
Varje sida har en h1. h2 och h3 delar upp innehållet i mindre delar.
class kan användas på flera element. id ska vara unikt på sidan.
CSS använder punkt för class och # för id.
Grid ordnar bildkorten i kolumner. På smala skärmar blir det en kolumn.
Flexbox används för logotypen, menyn och knappen i sidhuvudet.
En media query ändrar vissa avstånd när skärmen är högst 600 pixlar bred.
alt beskriver bilderna för den som inte kan se dem.

JavaScript steg för steg
querySelector hittar knappen med id textstorlek.
storText är en variabel som börjar som false.
hidden = false visar knappen när JavaScript fungerar.
addEventListener väntar på att besökaren klickar.
if och else väljer mellan större och vanlig text.
document.documentElement är html-elementet.
style.fontSize ändrar dess CSS-egenskap font-size till 20px.
Storlekar i rem följer html-elementets textstorlek.
Ett tomt värde återställer den vanliga textstorleken.
textContent ändrar texten på knappen.
aria-pressed berättar för hjälpmedel om knappen är aktiverad.
Valet återställs när en ny sida öppnas. Det sparas inte.

Kontroller utförda
Alla fyra sidor testades i Chromium vid 320, 390 och 1440 pixlars bredd.
Kontroller: en h1 per sida, bilder laddas, lokala sidlänkar finns,
ingen horisontell överströmning även med större text, ingen inline-CSS i HTML,
knappen förstorar och återställer texten, inga JavaScript-fel.
Hoppa till innehållet fungerar med tangentbord.
Menyn fungerar även när JavaScript är avstängt.
Startsidan har även granskats visuellt i mobil- och datorvy.
Detta är INTE ett resultat från SkyNet Technologies Accessibility Checker.
